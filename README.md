# Smart_Watch_Analysis

Project Overview

This project analyzes smart watch sensor data such as steps, heart rate, calories burned, sleep duration, and activity levels. The goal is to discover user health patterns and generate meaningful insights through data analysis and visualization.

Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Excel
Power BI
Dataset

The dataset contains smart watch sensor data including:

Daily Steps
Heart Rate
Calories Burned
Sleep Duration
Activity Level
Distance Covered
Project Workflow
1. Data Collection
Imported smart watch data from CSV files.
2. Data Cleaning & Preprocessing
Removed missing values.
Corrected inconsistent data formats.
Validated data for accuracy.
3. Exploratory Data Analysis (EDA)
Analyzed daily activity trends.
Examined heart rate patterns.
Studied relationships between steps, calories, and sleep.
4. Data Visualization

Created visualizations to understand:

Daily step counts
Heart rate distribution
Calories burned
Activity level trends
Sleep patterns
5. Dashboard Creation
Built interactive dashboards using Power BI.
Displayed key health metrics and user insights.
Key Insights
Identified peak activity periods.
Analyzed average heart rate trends.
Found relationships between activity and calorie burn.
Evaluated sleep and fitness patterns.
